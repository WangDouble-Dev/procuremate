# 个人采购工作台

为 DeepSeek Harness Desktop 0.2.0-rc.2 开发的独立插件。安装后在侧边栏增加「采购工作台」，可导入 Excel、复制纯文本询价、关联供货商和回填价格。

## 安装

1. 从 DeepSeek Harness Desktop 托盘或桌面设置中打开「Open DSH Terminal」。该终端使用当前激活的 profile。
2. 在这个终端执行：

   ```sh
   dsh plugin add '/Users/double/buyer/plugins/dsh-procurement-workbench-0.2.2.tgz'
   ```

3. 重启 Desktop，在侧边栏打开「采购工作台」。

安装命令按官方 Desktop 用户指南编写。本次没有更改正在使用的 Desktop profile；桌面内真实加载仍需安装后验收。如果桌面使用其他路径或机器，将命令中的路径替换为安装包实际位置。不要在普通终端猜测 Desktop 的 profile。

卸载时，在同一个 Desktop 终端执行 `dsh plugin remove dsh-procurement-workbench`，然后重启。卸载插件不会主动删除资料目录和目录设置。

## 使用

1. 在「供货商」中录入品牌、别名、供货商名称及微信或电话。可下载 Excel 模板批量导入。
2. 在「价格表」中导入品牌报价，填写型号、单位、币种、税务口径、运费条件、供货商和有效期。
3. 在「采购明细」导入 `.xls` 或 `.xlsx`，选择工作表、表头行及列对应关系。至少对应品牌、型号、数量列；单位用于报价匹配。
4. 勾选需要询价的行，编辑右侧纯文本，填写发送对象，选择「复制纯文本并存档」。自行粘贴至微信、电商客服或其他软件。
5. 选择「回填选中行价格」填入唯一有效的匹配报价。已有单价保留，可在表格内手动编辑。
6. 选择「导出整理版」，得到附带供货商联系方式、价格条件和绿色合作标记的新 Excel。

| 场景 | 已实现行为 |
| --- | --- |
| Excel 行复制成图片 | 仅向剪贴板写纯文本，可编辑、搜索、再次复制；不包含内部采购单价和供货商联系方式 |
| 合作品牌 | 品牌及显式别名精确匹配；合作行标绿并列出全部匹配供货商和联系方式 |
| 指定品牌价格 | 按品牌、型号、单位匹配；验证日期、起订量和计价条件；多个有效报价不自动选择 |
| 无合作供货商 | 显示已录入的人工核实渠道及来源，同时提供淘宝、京东、1688 和官网搜索入口 |
| 注意事项 | 可按品牌、品名/型号/备注关键词以及导入、询价、回填、导出场景显示提醒 |

## 文件保存与目录维护（0.2.0）

默认目录为当前系统用户的 `~/buyer/data/`；在这台机器上是 `/Users/double/buyer/data/`。供货商、价格表、渠道、注意事项、采购明细和询价记录集中存放在 `procurement-workbench.json`。第一次修改后创建文件，后续修改自动写入。顶部显示当前目录及保存状态；只有显示「已保存到文件」后才能确认本次修改完成。

不生成自动备份。原子保存期间使用临时文件，成功后替换正式文件。原有「导出备份／恢复备份」仍是手动操作。

更改目录：

1. 点击顶部「存储设置」，填写绝对目录路径，支持 `~/`。
2. 需要保留当前资料时，点击「复制当前资料并切换」。目标目录已有采购资料时停止，不覆盖；原目录文件保留，之后只更新新目录。
3. 需要读取已有目录时，点击「使用目标目录资料」。目标目录不存在数据文件时建立空资料；确认切换后显示该目录的数据。

目录选择记录在 `~/.config/dsh-procurement-workbench/storage.json`，与插件代码位置分离。插件升级或移动不会重置该设置。所有预览和 Desktop 实例共享这个选择；旧窗口保存时若发现目录或数据已变化，会阻止覆盖并提示重新载入。

0.2.2 已移除旧浏览器资料检测和迁移入口。工作台只读取所选目录的数据文件；不会检查或删除浏览器旧存档。如需导入已有 JSON 备份，可使用手动「恢复备份」。

保存失败时保留界面上的当前修改，并显示具体原因。可手动导出当前资料，再处理目录权限或其他窗口修改冲突；「重新载入」会放弃未保存的修改，读取文件中的版本。数据文件或目录设置损坏时显示错误，不会用空数据覆盖。

## 0.1.1 真实采购表适配

- 直接读取旧版 `.xls`，在前 30 行识别表头；支持「物料名称」「需求数量」「*含税单价(元)」等实际列名。
- 物料编码、包装规格和数量原样保留。「市场件／不限／其他」作为未指定品牌处理，按品名与规格搜索货源，不按品牌自动回填价格。
- 当前需求表的税务口径用于限制回填，报价有效期仍取自价格表，不从采购需求中的日期推断。
- 合并单元格的后续行不自动继承值，避免静默填错品牌；此类行需人工确认。
- 真实采购文件仅用于本地验收，不随插件包分发。

## 资料与限制

- 供货商、价格表、渠道和提醒均支持界面编辑、Excel 模板导入和 JSON 导入/导出。资料导入是替换操作，导入前有确认。
- JSON 示例位于 `templates/`，其中「示例品牌」等均为演示内容，不代表真实供货商或真实报价。渠道模板为空，避免预填未经核实的店铺。
- **渠道搜索尚未自动核实店铺归属，也不会自动从网页提取联系方式。** 没有品牌清单及可靠证据时，不声称某店是直营店。核实后在「渠道」保存网址、类型、来源网址和核实日期。
- 不自动发送微信消息、不登录电商账号、不自动下单。
- 支持二进制 `.xls` 和 `.xlsx`，暂不读取 `.xlsm`、HTML 伪装的 `.xls` 或图片。导入文件上限 20 MB、采购明细上限 10000 行；表头映射最多显示前 100 列。
- 公式单元格读取文件中的缓存结果，不执行或重新计算公式。应先在 Excel 中重新计算并保存。
- 导出的整理版保留映射的业务字段、有表头的其他原始列及新增的供货商/价格条件，不保留原样式、公式、宏和其他工作表；原文件不会被修改。
- 价格不自动换算币种、包装单位、税费或运费。目标列标明含税或未税时，只回填相同税务口径的报价；标明「元」时要求价格表币种为 CNY；历史采购价不会作为当前报价导入。不同有效报价同时匹配时停止回填，需整理价格表后再操作。注意事项是提示，不阻止操作。
- 0.2.0 起使用本机文件存储。同一系统用户、同一目录设置下，浏览器预览和 Desktop 读取同一份文件，不再按浏览器或端口隔离。存储接口仅允许本机请求。

## 开发与验证

```sh
npm ci --ignore-scripts
npm run build
npm test
npm run preview
```

预览地址为 `http://127.0.0.1:4173`。`node tests/ui.mjs` 使用本机 Google Chrome 的隔离测试环境验证导入、回填、剪贴板、导出、提醒、历史与窄屏布局。`node tests/storage-ui.mjs` 验证文件存储和目录维护。两套界面测试均自动启动独立临时资料目录与预览服务，不写入真实资料。Chrome 路径适用于 macOS，其他系统需要调整。

Host 注入公开 `webServer` 服务，注册独立 `/procurement-workbench/api` 路由，卸载时清理路由；不依赖 Desktop 私有服务。Client 使用公开 `main` keyed slot 和 `sidebar.panellist` list slot。以 `ctx.slots.inject` 跟随 owner 生命周期，不替换官方侧边栏。浏览器包内置 Excel 处理依赖，React 使用宿主实例。发布包无需在安装时构建。

本次验证范围记录在 `VALIDATION.md`。

### 询价文字格式

复制询价文字时，每件产品单独成块，序号、品牌、品名、型号 / 规格、数量等使用【标签】分行显示；复杂规格放在标题下一行，产品之间用分隔线区分。文字可直接粘贴到微信及电商聊天窗口。
